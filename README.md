# Kakei 家計簿

シンプルで使いやすい家計簿 Web アプリです。ビルド不要・サーバー不要で、データはブラウザ内(localStorage)に保存されます。
AI エージェント **Muse**(Windows ネイティブアプリとして提供予定)から、URL・テキスト・JSON で記帳できるように設計しています。

## 使い方

```bash
npm start        # http://localhost:8080 で起動(またはフォルダを任意の静的ホスティングに置くだけ)
npm test         # テキスト解析のテスト
```

### GitHub Pages で公開

1. GitHub のリポジトリで **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする(初回のみ)
2. `main`(または作業ブランチ)に push すると、`.github/workflows/pages.yml` がテスト後に自動公開します。Actions タブから手動実行も可能
3. 公開先: https://whitebirds4541-sketch.github.io/Kakei/ (リポジトリ名と同じく大文字・小文字を区別します)

すべて相対パスなので、サブパス配下でもそのまま動きます。

スマホでは「ホーム画面に追加」でアプリのように使えます(PWA・オフライン対応)。

### 画面

| 画面 | できること |
| --- | --- |
| ホーム | 残り予算、**先月との比較**、**6か月の推移**、部類別の支出(先月比つき)、最近の記録、ひとこと記帳、**カード明細PDFの読み込み** |
| 履歴 | 日別の一覧、検索、支出/収入の絞り込み。タップで編集・削除 |
| 設定 | 月の予算、**部類の追加・編集**、覚えた仕分け、Muse 連携、JSON/CSV の書き出し・読み込み |

- 右下の **＋** で金額 → カテゴリ → 保存の3ステップで記帳
- 追加・削除の直後は **元に戻す** が使えます
- ライト/ダークモードは端末の設定に合わせて自動で切り替わります

### カード明細PDFの読み込み

ホームの「カード明細PDFを読み込む」(またはPDFを画面にドラッグ&ドロップ)で、カード会社の「ご利用代金明細書」を取り込めます。

- 日付・店名・金額を読み取り、**部類に自動で仕分け**します(店名のキーワード → カード会社の業種欄の順で判定)
- 取り込み前に確認画面が出ます。自動で決まらなかったものは「その他」に入るので、右の欄で部類を変えてください。**同じお店はまとめて変わり、次回から覚えます**
- 明細に印字された「新規ご利用金額」と読み取った合計を照合して表示します
- 口座からの支払い(引き落とし)は家計の支出ではないため除外、返金・キャッシュバックは支出から差し引きます
- 同じ明細を二度読み込んでも、取り込み済みの行は自動で外れます
- 家族カード分も読み取り、誰の利用かを表示します
- PDFは端末の中だけで処理され、外部には送信されません

文字の対応表を持たないPDF(アメックスの明細など)も、日本語フォントの文字番号(Adobe-Japan1)から漢字を復元して読み取ります。画像だけのPDF(スキャン)は読めません。

### 部類(カテゴリ)

設定 → 部類 から追加・名前変更・削除ができます。初期状態で **投資・カード投資・出張費** なども用意しています。

- **キーワード**: 店名やメモに含まれていればその部類に自動で仕分けます
- **投資として集計**: オンにした部類は支出・予算に含めず「投資」として別に集計します(投資・カード投資は初期状態でオン)
- **覚えた仕分け**: 取り込み時や編集時に部類を変えたお店の一覧。不要なものは削除できます

### ひとこと記帳の書き方

| 入力 | 結果 |
| --- | --- |
| `ランチ 850` | 支出 · 食費 · ¥850 · 今日 |
| `昨日 電車 1,200円` | 支出 · 交通 · ¥1,200 · 昨日 |
| `11/20 ドラッグストア 540` | 支出 · 日用品 · 11/20 |
| `給料 25万` | 収入 · 給料 · ¥250,000 |
| `3000 交際 飲み代` | カテゴリを直接指定 |

## Muse 連携

設定画面の「Muse 連携」から使います。

1. **Muse への指示文をコピー** → Muse に貼り付けると、Muse が以下の形式で記帳してくれるようになります。
2. **今月のまとめを Muse 用にコピー** → 集計と明細を Muse に渡し、節約アドバイスなどを聞けます。
3. **Muse からの記帳データを貼り付け** → Muse が出力した JSON やテキストをまとめて取り込みます。

### URL で記帳

```
https://<設置先>/?add=ランチ%20850
https://<設置先>/?add=ランチ%20850%0A電車%20220        # 改行(%0A)で複数件
https://<設置先>/?entries=[{"amount":850,"category":"食費","memo":"ランチ"}]
```

開くと即座に記録され、URL からパラメータは消えます(リロードで二重登録されません)。

### JSON 形式

```json
[{ "date": "2026-11-27", "type": "expense", "amount": 850, "category": "食費", "memo": "ランチ" }]
```

- `type`: `expense`(支出)/ `income`(収入)。省略時はカテゴリから判断
- `category`: 食費・日用品・交通・住居・光熱・通信・娯楽・医療・衣服・美容・交際・その他 / 給料・副業・その他収入。一覧にない値はメモから推定
- `date`: 省略時は今日。`{"entries":[...]}` 形式や日本語キー(`金額`・`カテゴリ`・`メモ`・`日付`)も受け付けます

### ページ内 API

ブラウザを操作するエージェント向けに `window.kakei` を公開しています。

```js
kakei.add('ランチ 850');                 // テキスト or JSON オブジェクト(配列可)
kakei.summary('2026-11');                // { expense, income, balance, budget, byCategory }
kakei.list('2026-11');                   // その月の記録
```

## ファイル構成

```
index.html   画面
style.css    デザイン(ライト/ダーク)
parser.js    部類の初期値・自動仕分け・テキスト/JSON 解析(Node でもテスト可能)
pdfimport.js PDF明細の読み取り(文字の復元・行の組み立て・明細の解釈)
app.js       画面ロジック・保存・PDF取り込み・Muse 連携
vendor/      pdf-lib(MIT)、文字番号→文字の対応表(PDF読み込み時だけ読み込み)
sw.js        オフライン用 Service Worker
```
